# Intech Studio Profile

Premium digital product agency portfolio and profile website. Built for high performance, modern UX, and robust scaling.

## Tech Stack
- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **UI Components**: Radix UI / custom variants
- **Language**: TypeScript

## Development

```bash
# Install dependencies
npm install

# Run local server (http://localhost:3000)
npm run dev
```

## Features
- **i18n Support**: Native Context-based bilingual setup (EN/ID) stored in LocalStorage.
- **Glassmorphism & Advanced UI**: High-fidelity CSS/SVG illustrations over raster images for extreme performance.
- **Mobile Optimized**: Responsive layouts and layout shift prevention.

## Deployment
Ready to be deployed on Vercel or any standard Node.js hosting.

```bash
npm run build
npm run start
```
